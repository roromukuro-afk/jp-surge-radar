# ラベル定義

定義は事前に決めて固定したもので、過去データへの当てはめで決めていない。
ラベルは「実際にどういう形・出来事だったか」を表し、**良い・悪い・健全・理想・強い・好材料・悪材料などの評価語は使わない**。
変更するときは下の「変更履歴」に日付・理由を書き、それ以前に付けたラベルは付け直さない。

教師データ(自分が出した候補)と今回の候補は、必ず同じ定義で表す。
**不明(データが足りず計算できない)は「該当なし」と区別する。** 数値が None のときはラベルを付けず、
比較の集計では分母から外す。

## 1. チャート・出来高ラベル(版 chart-v2。3000 円以下の全銘柄に機械的に付ける)

「直前 N 日」は基準日を含まない直前 N 営業日。価格は各銘柄の日足(Yahoo)。売買代金は **終値×出来高の近似**。
VWAP は日足データに無いので扱わない(不明)。

### A. 高値・安値構造
直近 5 日(基準日含む)の最高値・最安値を、その前の 5 日と比べる。差が ±1% 以内は横ばい。

| ラベル | 定義 |
|---|---|
| `高値切り上げ` / `高値切り下げ` / `高値横ばい` | 直近 5 日最高値 ÷ 前 5 日最高値 − 1 が +1% 超 / −1% 未満 / その間 |
| `安値切り上げ` / `安値切り下げ` / `安値横ばい` | 最安値について同じ |

「高値・安値とも切り上げ」などの複合は、この 2 つの組み合わせとして扱い、独立した証拠として数えない。

### B. 基本トレンド(20 日線 = 基準日を含む直近 20 日の終値平均)
| ラベル | 定義 |
|---|---|
| `上昇トレンド` | 20 日線の 5 日間の変化率 > +2%、かつ終値 > 20 日線 |
| `下降トレンド` | 同 < −2%、かつ終値 < 20 日線 |
| `横ばい` | 同の絶対値 ≤ 2% |

### F. ローソク足(基準日の足。比率は前日終値比)
| ラベル | 定義 |
|---|---|
| `大陽線` / `中陽線` / `小陽線` | 終値>始値で、実体が +5% 以上 / +2% 以上 / それ未満 |
| `大陰線` / `中陰線` / `小陰線` | 終値<始値で、実体が −5% 以下 / −2% 以下 / それ以外 |
| `十字線` | 実体 ≤ 日中値幅の 10% |
| `長い上ヒゲ` | 上ヒゲ ≥ 日中値幅の 50%、かつ日中値幅 ≥ 前日終値の 3% |
| `長い下ヒゲ` | 下ヒゲについて同じ |
| `高値引け` / `安値引け` | 終値 ≥ 高値×0.999 / 終値 ≤ 安値×1.001 |
| `窓開け上昇` / `窓開け下落` | 安値 > 前日高値 / 高値 < 前日安値 |
| `陽線2本連続` / `陽線3本連続` / `陽線4本以上連続` | 基準日から遡って陽線が続いた本数(該当する最長の 1 つだけ) |
| `陰線2本連続` / `陰線3本連続` / `陰線4本以上連続` | 陰線について同じ |
| `陽の包み足` / `陰の包み足` | 前日と逆向きの足で、実体が前日の実体を包む |
| `はらみ足` | 高値 < 前日高値 かつ 安値 > 前日安値 |

### G. 高値・安値への距離(N = 5, 10, 20)
| ラベル | 定義 |
|---|---|
| `N日高値更新` | 基準日の高値 > 直前 N 日の最高値 |
| `N日高値接近` | 更新しておらず、終値が直前 N 日最高値の −3%〜0% |
| `N日安値更新` / `N日安値接近` | 安値について同じ(接近は終値が直前 N 日最安値の 0%〜+3%) |
| `10日高値から5〜15%下` | 終値が直前 10 日最高値の −15%〜−5% |

### H. 移動平均(終値の単純平均)
| ラベル | 定義 |
|---|---|
| `5日線上` / `5日線下`、`20日線上` / `20日線下` | 終値と線の位置 |
| `20日線回復` / `20日線割れ` | 前日終値が前日の 20 日線以下で基準日終値が上 / その逆 |
| `20日線上向き` / `20日線下向き` / `20日線横ばい` | 20 日線の 5 日間変化率 > +1% / < −1% / その間 |
| `5日線20日線収束` | 5 日線と 20 日線の差 ≤ 1% |

### J. 値幅(日中値幅 = (高値−安値) ÷ 前日終値)
| ラベル | 定義 |
|---|---|
| `値幅収縮` / `値幅拡大` | 直近 5 日の平均日中値幅 ÷ 直近 20 日の平均 ≤ 0.7 / ≥ 1.3 |

ATR は 14 日の真の値幅の単純平均として数値(`atr14`, `atr14_pct`)で保存する。

### 出来高・売買代金
| ラベル | 定義 |
|---|---|
| `出来高急増` / `出来高増加` / `出来高減少` | 基準日出来高 ÷ 直前 20 日平均 ≥ 3 / 1.5〜3 / ≤ 0.5 |
| `価格上昇＋出来高増加` ほか 6 種 | 出来高が直前 20 日平均の 1.5 倍以上(増加)または 0.7 倍以下(減少)のとき、基準日の騰落が +1% 以上 / −1% 以下 / その間で「上昇・下落・横ばい」を組み合わせる |
| `出来高漸増` | 直近 5 日平均出来高 ÷ その前 20 日平均 ≥ 1.3、かつ直近 5 日にその前 20 日平均の 3 倍以上の日が無い |
| `出来高収縮` | 同比 ≤ 0.6 |
| `売買代金レジーム上昇` | 直前 5 日平均売買代金 ÷ 直前 20 日平均 ≥ 2 |
| `20日平均売買代金3000万円未満` | 直前 20 日平均売買代金 < 3,000 万円 |

### 値幅制限・急変
| ラベル | 定義 |
|---|---|
| `ストップ高引け` / `ストップ高タッチ` / `ストップ安` | 東証の制限値幅表による。タッチは高値が届いたが引けていない |
| `1日+10%以上` / `1日-7%以下` / `5日+30%以上` | 騰落率 |

制限値幅表: 前日終値 100 円未満 30 円、200 円未満 50 円、500 円未満 80 円、700 円未満 100 円、
1,000 円未満 150 円、1,500 円未満 300 円、2,000 円未満 400 円、3,000 円未満 500 円、5,000 円未満 700 円。

### 数値特徴(features に保存)
騰落 `ret_1d/3d/5d/10d/20d`、高値安値 `high_N` `low_N` `dist_high_N` `dist_low_N`(N=5,10,20)、
`ma5` `ma20` `ma20_slope5`、`range_1d` `range_avg5` `range_avg20` `atr14` `atr14_pct`、
`volume` `vol_avg5` `vol_avg20` `vol_ratio5` `vol_ratio20` `vol_trend`、
`turnover_approx` `turnover_avg5` `turnover_avg20`、`body_pct` `upper_wick_pct` `lower_wick_pct` `gap_pct`、
`bull_run` `bear_run`、`hh_ratio` `ll_ratio`。

## 2. チャートの形(Claude が候補を詳しく見るときに付ける)

三角持ち合い・ダブルボトム・逆三尊・フラッグ・カップ・アンド・ハンドル・高値圏持ち合い・
抵抗線接近・支持線反発などの形は、機械的には付けない。Claude が日足を見て付け、
**必ず根拠(どの期間の、どの高値・安値・値幅か)を併記する**(`chart_patterns`)。
定義を確認できない名称は使わず、観測した高値・安値の構造をそのまま書く。

## 3. 材料ラベル(版 material-v1。Claude が見出しを読んで付ける)

手順は `procedures/label.md`。1 つの見出しに独立した出来事が複数あれば **原子的イベント** に分け、
イベントごとに以下の 6 軸を付ける。**材料の良し悪しは付けない**(何が起きたかだけ)。

| 軸 | 値(どれか 1 つ。作用経路のみ複数可) |
|---|---|
| 1. イベント種別 | 業績実績 / 業績見通し / 商取引・顧客 / 提携・アライアンス / 製品・サービス・技術 / 生産・設備・供給 / M&A・事業再編 / 規制・承認 / 臨床・研究 / 法務・知財 / 資金調達・株式供給 / 株主還元・資本構成 / 上場・指数・市場制度 / 経営・ガバナンス・人事 / 政策・財政 / 金融・マクロ / 地政学・貿易 / 商品・外部価格 / セクター・同業波及 / その他 |
| 2. 発生主体 | 当該企業 / 顧客 / 取引先 / パートナー / 競合企業 / 同業企業 / 供給者 / 政府 / 規制当局 / 中央銀行 / 裁判所 / 国際機関 / 取引所 / Index提供者 / 市場 / その他 |
| 3. 作用経路 | 売上 / 受注残 / 販売数量 / 販売価格 / 市場需要 / 利益率 / 原材料コスト / 人件費 / 金利負担 / 資金調達 / 現金・流動性 / 生産能力 / 供給能力 / 市場アクセス / 規制承認 / 知的財産 / 法的負担 / 資産価値 / 株式供給 / Float / 株主構成 / 支配権 / 割引率 / 取引需給 / その他 |
| 4. 影響範囲 | 企業固有 / 企業間 / サブ業界 / 業界 / セクター / 国内マクロ / グローバルマクロ |
| 5. 進行段階 | 報道・観測 / 計画・提案 / 正式発表 / 契約締結 / 決定 / 承認 / 実施開始 / 完了 / 実績・結果判明 |
| 6. 公開タイミング | 寄り前 / 市場時間中 / 引け後 / 非営業日 / 公開時刻不明 — **公開日時から機械的に決める**(Claude は付けない) |

イベント種別の細目(上方修正、新規受注、第三者割当、自社株買い など)と金額・規模は、`facts`(新しく判明した事実の要約)に書く。
大口契約・大型契約・巨額契約のように言い換えでイベント種別を増やさない。

公開タイミングの区切り(東証): 寄り前 = 営業日の 9:00 より前、市場時間中 = 9:00〜15:30、
引け後 = 15:30 より後、非営業日 = 土日祝。公開時刻が分からない見出しは「公開時刻不明」。
