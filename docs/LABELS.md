## チャート・出来高ラベル(機械的に計算、3000 円以下の全銘柄)

「直近 2 週」は当日を除く直前 10 営業日、「直近 1 か月」は当日を除く直前 20 営業日。
足が足りない銘柄・期間は該当ラベルを付けない(1 か月系は開始から約 2 週間は付かない)。

| ラベル | 定義 |
|---|---|
| `ブレイク2週` | 終値 > 直近 2 週の高値 |
| `ブレイク1か月` | 終値 > 直近 1 か月の高値 |
| `2週高値圏` | 終値が直近 2 週高値の -3% 〜 0% |
| `押し目` | 終値が直近 2 週高値の -15% 〜 -5%、かつ直近 2 週安値の +3% より上 |
| `保ち合い` | 直近 2 週の (最高値 ÷ 最安値 − 1) < 8% |
| `出来高急増` | 当日出来高 ≥ 直近 2 週平均の 3 倍 |
| `出来高増` | 当日出来高が直近 2 週平均の 1.5 倍以上 3 倍未満 |
| `出来高枯れ` | 当日出来高 ≤ 直近 2 週平均の 0.5 倍 |
| `ストップ高引け` | 終値 ≥ 前日終値 + 値幅制限 |
| `ストップ高タッチ` | 高値 ≥ 前日終値 + 値幅制限、かつストップ高引けではない |
| `ストップ安` | 終値 ≤ 前日終値 − 値幅制限 |
| `ギャップアップ` | 始値 ≥ 前日終値 × 1.03 |
| `上ヒゲ長` | (高値 − max(始値, 終値)) ≥ 日中値幅の 50%、かつ日中値幅 ≥ 前日終値の 3% |
| `連騰3` | 3 日以上連続で終値が前日を上回る |
| `急騰` | 当日の騰落率 ≥ +10% |
| `急落` | 当日の騰落率 ≤ −7% |
| `値幅大` | 直近 2 週の平均日中値幅(前日終値比) ≥ 6% |
| `値幅小` | 同 < 2% |
| `低流動性` | 直近 2 週の平均売買代金 < 3,000 万円 |

値幅制限は東証の制限値幅表(前日終値 100 円未満 30 円、200 円未満 50 円、500 円未満 80 円、
700 円未満 100 円、1,000 円未満 150 円、1,500 円未満 300 円、2,000 円未満 400 円、
3,000 円未満 500 円、5,000 円未満 700 円、7,000 円未満 1,000 円)による。

## 材料ラベル(Claude が見出しを読んで付ける)

手順は `procedures/label.md`。1 見出しにつき以下を付ける。

| 項目 | 値 |
|---|---|
| `subjects` | その見出しが実際に扱っている銘柄コード。並んでいるだけの銘柄は含めない。主役がいない市況記事は空 |
| `kind` | 決算 / 業績修正 / 受注・契約 / 提携・M&A / TOB・MBO / 資本政策 / 株主還元 / 新製品・新事業 / 許認可・規制 / 人事・組織 / 不祥事・訴訟 / 値動き解説 / まとめ・市況 / その他 |
| `direction` | +2(強い好材料) / +1 / 0 / −1 / −2(強い悪材料)。主役の銘柄にとっての向き |
| `scheduled` | 事前に日程が分かっていた出来事か(決算発表など): yes / no / unknown |
