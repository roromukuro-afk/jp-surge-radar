# 材料ラベル付けの手順(Claude 用)

版: label-v1 (2026-09-26)

## 目的

その日に取得したニュース見出しを読み、`docs/LABELS.md` の材料ラベルを付ける。
ラベルはその日のうちに付け、**後から付け直さない**。

## 読んでよいもの

- `scripts/news_to_label.py` が出す、未ラベルの見出しと、その見出しが紐付いた銘柄のコード・社名
- それだけ。株価・候補・過去の成否は見ない(ラベルが値動きに引きずられるのを防ぐため)

## 手順

1. `python scripts/news_to_label.py --limit 300` を実行する。同じ見出しは 1 件にまとめられ、
   紐付いた銘柄の一覧が付いて出てくる。
2. 各見出しについて判断する。
   - **subjects**: 見出しが実際に扱っている会社のコード。紐付いた銘柄の中から選ぶ。
     「決算まとめ」「ストップ高一覧」「ランキング」のように社名が並んでいるだけの記事では、
     並んでいる銘柄を主語にしない。主役がいなければ空にする。
     社名が略称でも(例:「日石輸」)、紐付いた社名と一致するなら主語とみなす。
     紐付いた銘柄とは別の会社の記事なら空にする。
   - **kind / direction / scheduled**: `docs/LABELS.md` の選択肢から選ぶ。
     direction は主役の会社にとっての向き。判断できなければ 0。
     見出しから読み取れないことは推測で埋めない。
3. 結果を JSON にして `python scripts/save_labels.py <ファイル>` で保存する。形式:
   ```json
   [{"title_key": "...", "subjects": ["1234"], "kind": "業績修正",
     "direction": 2, "scheduled": "no"}]
   ```
4. 未ラベルが残っていれば 1 に戻る。新しい日付から順に出てくるので、候補選定に効く直近の見出しが先に
   ラベル付けされる。その日のうちに終わらなければ、`--count` で残件数を確認して報告に書き、翌日に続ける。
   黙って捨てない。
