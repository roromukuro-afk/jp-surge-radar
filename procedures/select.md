# 候補選定の手順(Claude 用)

版: select-v1 (2026-09-26)

## 問い

**基準日の終値から、翌営業日以降 10 営業日以内に、場中高値で +20% に届く銘柄はどれか。**

1 日 10 銘柄前後を選ぶ。10 銘柄も根拠のあるものが見つからなければ 5 銘柄程度でよい。
数合わせで弱い銘柄を入れない。

## 読んでよいもの

- 基準日のスナップショット(3000 円以下の全銘柄の特徴量とチャート・出来高ラベル)
- 各銘柄の直近の日足(開始日以降に保存されたもの)
- 基準日までに出たニュース見出しと、その材料ラベル
- 銘柄台帳(社名・市場)
- **自分が過去に出した候補と、その成否**(手順 1)

## 読んではいけないもの

- 基準日より後の株価(基準日が過去の場合も含む)
- 旧システムのデータ・コード・git 履歴(`jp_surge_radar_backup_20260926` を含む)
- Web 検索による、その銘柄のその後の値動きの情報

## 手順

### 1. 自分の成績を振り返る

`python scripts/review.py` を実行する。判定が確定した自分の候補について、
成功・失敗と、選んだときのラベル・理由・その後の最高値が出る。

- どのラベルの組み合わせ・どの理由で選んだものが当たり、外れたかを見る。
- 気づいたことを `notes` として今日の記録に残す(手順 5)。
- 選び方を変える場合は、この文書の末尾「変更履歴」に、日付・何を変えたか・
  根拠にした自分の候補の件数と成否を書く。根拠は自分の候補の実績だけとし、
  一般論や過去の相場の知識では変えない。

### 2. 候補の母集団を作る

`python scripts/select_context.py --pool` を実行する。以下のどれかに当てはまる銘柄が並ぶ。

- `出来高急増` / `ブレイク2週` / `ブレイク1か月` / `ストップ高引け` / `ストップ高タッチ` / `急騰`
- 基準日までの 3 営業日以内に、その銘柄が主語で direction が +1 以上の材料がある

この条件は「見落とさないための入口」であって、選ぶ基準ではない。これ以外の銘柄を
自分で探して加えてもよい(`scripts/select_context.py --labels 押し目,出来高増` のように、
ラベルの組み合わせで銘柄を引ける)。

### 3. 1 銘柄ずつ読む

`python scripts/select_context.py --code <コード>` で、直近の日足・ラベル・材料をまとめて見る。
以下を考える。

- **動く理由があるか**: 主語になっている材料の中身。すでに株価に織り込まれていないか
  (材料が出た日にもう大きく上げていないか)。続報や思惑が続きそうか。
- **+20% の余地があるか**: 20% 上の価格までに、直近で売りが出た価格帯があるか。
  日々の値幅から見て、10 営業日で 20% 動くことが現実的か。
- **崩れる理由はないか**: 増資・希薄化、上ヒゲの連続、出来高を伴った下落、
  材料出尽くし、低流動性。

### 4. 選ぶ

5〜10 銘柄を選び、確信の強い順に並べる。

### 5. 記録する

`python scripts/save_candidates.py <ファイル>` で保存する。形式:

```json
{
  "base_date": "2026-09-25",
  "procedure": "select-v1",
  "pool_size": 123,
  "notes": "手順 1 で気づいたこと。まだ判定済みの候補がなければその旨",
  "candidates": [
    {
      "code": "1234",
      "rank": 1,
      "conviction": 4,
      "thesis": "なぜ 10 営業日で +20% に届くと考えたか",
      "trigger": "何が起きれば上がるか",
      "risk": "何が起きれば崩れるか",
      "chart_view": "チャートの形を自分の言葉で(例: 2 週保ち合いを出来高急増で上抜け)"
    }
  ]
}
```

conviction は 1(弱い)〜 5(強い)。基準終値とスナップショットのラベルは保存時に自動で記録される。
